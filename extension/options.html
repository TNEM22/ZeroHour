The browser frame

An extension cannot recolour the window frame, tabs or toolbar. Only an installed theme can, its colours are fixed in that package, and no API can change or install one for you. The frame is near-black in every palette, so one graphite theme sits correctly under all of them.

Get the matching theme

The theme listings are not live yet. Until they are, the frame keeps whatever theme you already have.

Beyond the new tab

Restyles scrollbars, text selection and form accents on the sites you visit. Turning this on asks for access to websites; turning it off revokes it again.

Settings sync to every device signed in to the same browser profile, through the browser's own sync. Nothing is sent anywhere else.
